# Three-minute judge demo

All preloaded records are **synthetic**. Use the private demo password from `.env`, not a printed credential. Keep the teacher and student signed in in separate browser profiles/windows, or sign out between roles. Read-only `/demo` offers a safe alternative when there is no time to log in.

Before presenting: run `docker compose up -d`; check health; log in to verify both roles; select **Grade 7 · Everyday mathematics**. Student01 begins with an untouched original diagnostic in a fresh seed. Smoke checks may have added separate diagnostics; select **Small questions, useful clues** for the original exercise. Never accelerate a real school's clock.

**0:00–0:25 · Begin on `/` with the original yellow bulb notebook art visible.**

“A wrong answer is a clue. In a classroom sharing devices or working on paper, a teacher needs a useful next step—not another leaderboard. AhaBridge connects five steps: notice, understand, bridge, teach back and check what remains.”

Click **Explore demo classroom**, select **Find the why**, then select **Fractions**. Point to accuracy, confidence mismatch, question/option evidence and heuristic weights. “These are possible misunderstandings. The teacher sees the evidence; we don't diagnose a child.”

**0:25–1:05 · Start the live learner response.**

Teacher: sign in → **Author & invite → Diagnostic sets**. Select two fraction diagnostic questions, title the set “Today’s fraction clues”, **Save draft → Publish to classroom**. Student: sign in → **My exercises → Today’s fraction clues → Open exercise**. Choose a tagged wrong option (B in the seed), explicitly select **I’m sure**, **Save & continue**. Answer the second question, then **Submit exercise**. “A confident wrong answer and an uncertain wrong answer are different teaching clues. Neither becomes an automated grade.”

**1:05–1:40 · Bridge the idea.**

Teacher: **Classroom atlas → Fractions → Choose a bridge**. In **Bridge planner**, select **Paper fractions, real understanding**, **Unfold the activity**. Show materials, steps and observable criteria. **Assign bridge → Learner 01 → Confirm assignment**. To demonstrate review, choose **Edit a copy**, make an actual adaptation, save and approve that new copy before assigning it. “The teacher approves practical work. The activity needs paper and a pencil, not an AI subscription.”

**1:40–2:15 · Hear the learner explain.**

Student: **Bridge missions**, complete the paper activity, **I’ve tried the activity**. In **Teach it back**, write an explanation of equal-sized pieces and a different example, optionally sketch, then **Send to my teacher**. Teacher: **Teach-back review**, inspect that exact explanation, select rubric values only when justified, write supportive feedback and **Save teacher review**. “Completing a task isn't mastery. A teacher listens for clarity, correctness, a useful example and transfer.”

**2:15–2:40 · Check what stayed.**

Student: **Echo checks**. Show its real 72-hour due time and “Not yet assessed”. For the synthetic demonstration only, click **Synthetic demo only: make this check due**. Answer the different equivalent problem and **Save Echo Check**. “We compressed time explicitly for the demo. Real classrooms wait 48–72 hours; nothing missed is labelled failed.”

**2:40–3:00 · Close with evidence and limits.**

Teacher: **Learning evidence**. Show record counts and delayed N. A correct Echo plus a supportive reviewed rubric and prior error can add an observed recovery. “This is a small synthetic sample, not proof of causal impact. Our SDG 4 contribution is a more inclusive, teacher-controlled recovery loop: paper-ready activities, limited device caching, primary-label translations, and a clear trail from an answer to the next teaching action.”

Takeaway: **“AhaBridge helps a teacher turn a wrong answer into a practical bridge—and check whether the idea still holds three days later.”**

## Six-slide pitch outline (text, not a generated deck)

1. **Every mistake is a map.** Classroom problem, shared devices, limited intervention time, supplied artwork.
2. **The missing connection.** Eedi, DIKSHA, Kolibri and Plickers have related diagnostic/content/offline/paper capabilities. Our contribution is this integrated, teacher-verified workflow, not first-in-world novelty.
3. **Five steps, one evidence trail.** Diagnostic, possible misconception evidence, approved activity, reviewed explanation, distinct delayed check.
4. **Show the working notebook.** Live role-scoped PostgreSQL records; exact option checks; transparent heuristic priorities; private learner work; synthetic fixtures explicitly labelled.
5. **Built for participation.** Print packs, manual paper response entry, limited saved-device content, English/Hindi/Odia navigation and fraction activities, readable text and reduced motion. SDG 4.1: quality learning; 4.4: practical numeracy; 4.5: participation across access constraints; 4.a: supportive learning environments. Alignment is intended, not a measured SDG outcome.
6. **What comes next, with evidence.** School-reviewed translations and activities, consented pilots, validated thresholds, accessible-user testing, longer-term comparisons, stronger operational tooling. Ask for teacher feedback and a small authorized pilot, not a claim of proven learning gains.
